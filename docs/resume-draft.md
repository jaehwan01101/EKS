# 이력서 초안 v2

## 쓰는 기준 (지켜야 할 것)

- **판단 → 조치 → 결과** 순서. "무엇을 했다"가 아니라 "왜 필요하다고 판단했고, 무엇을 해서, 무엇이 달라졌나"
- 결과에는 **숫자나 검증된 사실**이 있어야 한다. 숫자는 측정한 것만 쓴다
- 기술 키워드 나열 금지. 누구나 겪는 설정 에러와 해결(예: Argo CD의 ServerSideApply)은 쓰지 않는다
- 문장은 읽기 쉽게. 한 항목 2~3문장
- 아직 만들지 않은 것은 쓰지 않는다

## 지금 쓸 수 있는 항목 (검증된 것만)

**접근 경로 최소화**
운영자 접속 경로가 곧 공격 경로라고 판단해, EKS API 서버를 비공개로 두고 SSH 대신 SSM Session Manager로만 접속하는 점프 호스트를 구성했습니다. 인바운드 허용 규칙과 SSH 키가 없는 구조입니다(각 0개).

**파드 밀도 한계 해소**
파드가 VPC IP를 하나씩 쓰기 때문에 기본 설정에서는 노드(2vCPU·8GB)당 파드가 29개로 제한됩니다(AWS 공식 계산식: ENI 3 × (IP 10 - 1) + 2). VPC CNI의 prefix delegation을 적용해 한도를 110개로 늘리고 노드에서 직접 확인했습니다.

**장기 키 없는 CI**
CI의 AWS 접근에 장기 액세스 키를 쓰면 유출 시 만료 전까지 악용될 수 있다고 판단해, GitHub OIDC로 실행마다 발급되는 임시 자격 증명으로 대체했습니다. 역할을 저장소·브랜치·불변 ID 조건으로 제한하고, main 이외 브랜치에서 역할 획득이 거부되는 것까지 테스트로 확인했습니다. 서드파티 Action은 커밋 SHA로 고정하고 배포 후 2주가 지난 버전만 채택해 태그 변조 유형의 공급망 공격에 대비했습니다.

## 측정 후 완성할 항목 (수치를 채우면 쓴다)

**유휴 비용 통제**
클러스터를 내려둔 4일간 크레딧이 하루 약 1.8달러씩 소진되는 것을 청구 데이터로 확인하고, 주된 원인인 NAT Gateway의 상시 과금을 찾았습니다. VPC는 유지한 채 NAT만 끌 수 있도록 Terraform을 변수화하고 세션 종료 절차를 만들었습니다. → 적용 후 유휴 비용 [__]달러/일 (측정 필요)

**CI/CD 분리와 배포 시간**
CI가 클러스터에 접근하지 않고 Git에 이미지 태그만 커밋하면 Argo CD가 가져가 반영하는 방식으로 구성해, CI가 가진 클러스터 권한을 0으로 했습니다. → 커밋부터 파드 교체 완료까지 [__]분, 롤백 소요 [__]분 (측정 필요)

**재현성**

## 이력서에 넣지 않는 것 (그리고 이유)

| 항목 | 이유 | 어디에 쓰나 |
|---|---|---|
| ESO CRD 어노테이션 한도, Server-Side Apply | 널리 알려진 흔한 에러, 한 줄 설정 추가가 해결의 전부 | 면접 답변 연습용 |
| app-of-apps, sync wave | 기본 개념이고 결과 수치가 없음 | 면접 답변 연습용 |
| KMS, Pod Identity 나열 | 키워드 나열. 판단과 결과가 없음 | 필요 시 접근 경로 항목에 한 줄로 |
| Terraform 레이어 분리 | 구조 설명일 뿐 결과가 없음 | 유휴 비용 항목의 수단으로만 |
| OIDC 에러 디버깅 과정, uid 충돌, 무료 플랜 제약 | 통과의례 수준의 문제 | 면접 답변 연습용 (engineering-log.md) |
| 불변 태그, 재실행 멱등성 | 좋은 설계지만 지면 대비 임팩트가 작음 | 면접 답변 연습용 |
